# Makibul Hossain Tamim — Portfolio

Personal portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Local development

```sh
npm install
npm run dev
```

Open http://localhost:3000. To check the production version:

```sh
npm test
npm run lint
npm run build
npm start
```

## Content

Edit `app/data/portfolio.ts` for profile information, experience, capabilities,
projects, education, certifications, recommendations, and contact links.
`featured: true` places a project in the main grid; other projects appear under
“Explore more work.” Project context and existing Figma/live links remain
available in the expandable details.

The homepage introduces the founder, shows selected work, explains the studio,
and includes capabilities, experience, recommendations, credentials, and contact.
The neutral palette and typography are defined in `app/globals.css`.

## Contact configuration

Copy `.env.example` to `.env` and supply the email settings it describes.
Keep credentials out of source control. The contact endpoint is
`app/api/contact-me/route.ts`.

## Contact behavior and checks

The contact form supports keyboard submission, inline field errors, autofill,
and persistent delivery status. Name, email, subject, and message are validated
on the client and server. The optional subject is included in the delivered
email, and Reply-To points to the sender. Submitted content is escaped in HTML.

SMTP uses implicit TLS on port 465 and STARTTLS on other configured ports,
with normal certificate verification and connection timeouts. Configure the
existing email variables before expecting real delivery. Automated checks do
not send email. The existing process-local rate limit remains one valid attempt
per minute per IP address; it does not share state across serverless instances.

`npm test` uses Node's built-in TypeScript support to check validation, message
formatting, and rate limiting. Use a Node version that supports the
`--experimental-strip-types` flag.

## Sharing and discovery

`siteConfig.url` in `app/data/portfolio.ts` is the public URL used for canonical
metadata, `robots.txt`, and `sitemap.xml`. Update it if the public domain changes.
The branded sharing image is generated by `app/opengraph-image.tsx`; the browser
icon is `app/icon.svg`. Both use the portfolio's neutral palette.
